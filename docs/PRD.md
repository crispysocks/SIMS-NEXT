## 学生管理系统需求文档（V2.0）

### 1. 项目概述

本项目开发一个面向普通学校（含小初高）的学生管理系统，基于FastAPI构建，提供学生信息管理、成绩考核管理、班级管理、教师管理四大核心模块。系统采用RESTful API设计，支持前后端分离架构。

---

### 2. 功能需求

#### 2.1 学生基本信息管理模块

| 功能 | 说明 |
|------|------|
| 创建学生 | 学号、姓名、性别、年龄、籍贯、班级编号、入学时间 |
| 查询学生 | 支持按学号、姓名、班级等条件筛选 |
| 更新学生 | 修改学生基本信息 |
| 删除学生 | 逻辑删除（标记删除态） |

#### 2.2 成绩考核管理模块

| 功能 | 说明 |
|------|------|
| 录入成绩 | 按考试名称录入（学号、考试名称、成绩） |
| 考试名称 | 全校统一（见附录） |
| 修改成绩 | 更新指定学生某次考试成绩 |
| 删除成绩 | 删除指定学生某次考试记录 |

#### 2.3 班级管理模块

| 功能 | 说明 |
|------|------|
| 创建班级 | 班级编号、班级名称、班主任编号 |
| 查询班级 | 按班级编号或名称筛选 |
| 更新班级 | 修改班级信息 |
| 删除班级 | 逻辑删除 |

#### 2.4 教师管理模块

| 功能 | 说明 |
|------|------|
| 创建教师 | 教师工号、姓名、性别、入职时间 |
| 查询教师 | 支持按工号、姓名筛选 |
| 更新教师 | 修改教师信息 |
| 删除教师 | 逻辑删除 |

---

### 3. 实体关系设计

```
学生 ────── 属于 ────── 班级
  │
  └─── 参与 ────── 考试 ────── 对应成绩

教师 ────── 担任 ────── 班主任（班级）
```

- 学生与班级：**N:1**（一个学生属于一个班级）
- 成绩与学生：**N:1**（一个学生有多次成绩记录）
- 班级与班主任（教师）：**N:1**

---

### 4. API设计概要

#### 4.1 学生信息端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /students | 获取学生列表 |
| POST | /students | 创建学生 |
| GET | /students/{id} | 获取学生详情 |
| PUT | /students/{id} | 更新学生信息 |
| DELETE | /students/{id} | 逻辑删除学生 |

#### 4.2 成绩考核端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /scores | 获取成绩列表（支持按学号、考试名称筛选） |
| POST | /scores | 录入成绩 |
| PUT | /scores/{id} | 修改成绩 |
| DELETE | /scores/{id} | 删除成绩 |

#### 4.3 班级管理端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /classes | 获取班级列表 |
| POST | /classes | 创建班级 |
| GET | /classes/{id} | 获取班级详情 |
| PUT | /classes/{id} | 更新班级 |
| DELETE | /classes/{id} | 逻辑删除班级 |

#### 4.4 教师管理端点

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /teachers | 获取教师列表 |
| POST | /teachers | 创建教师 |
| GET | /teachers/{id} | 获取教师详情 |
| PUT | /teachers/{id} | 更新教师信息 |
| DELETE | /teachers/{id} | 逻辑删除教师 |

---

### 5. 技术栈

- **后端框架**：FastAPI
- **数据库**：MySQL
- **数据验证**：Pydantic
- **API文档**：Swagger（自动生成）

#### 6.2 字段设计概要

**学生表（students）**
- id, 学号, 姓名, 性别, 年龄, 籍贯, 班级编号, 入学时间, 删除标记, 创建时间, 更新时间

**班级表（classes）**
- id, 班级编号, 班级名称, 班主任工号, 删除标记, 创建时间, 更新时间

**教师表（teachers）**
- id, 工号, 姓名, 性别, 入职时间, 删除标记, 创建时间, 更新时间

**成绩表（scores）**
- id, 学号, 考试名称, 成绩, 创建时间, 更新时间
