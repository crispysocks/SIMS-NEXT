# AI Tutor — 已知限制与未来方向

## 当前限制

### 数学引擎

| 限制 | 影响 | 缓解措施 |
|------|------|----------|
| **仅支持单变量 x** | 无法出多元方程、偏导数题 | 当前 5 个 topic 均为单变量，够用 |
| **仅 15 个模板** | 题目多样性有限，学生可能记住模式 | 模板参数范围足够大（系数随机），实际重复概率低 |
| **无 LaTeX 正式渲染** | 题目展示为 SymPy 字符串（如 `x**2` 而非 x²） | Streamlit 不支持完整 LaTeX，当前格式 Stremalit 可渲染 |
| **无解题步骤生成** | 只能判断对错，不能给出分步解答 | MVP 聚焦核心循环，后续可加入 `sympy.solve` 分步输出 |
| **二次方程答案格式固定** | 答案要求逗号分隔如 `-1,-4`，`x=-1,x=-4` 判错 | `safe_compare` 做 tuple 级比较，但格式不够灵活 |
| **因式分解不验证形式** | `x²+5x+6` 答 `x²+5x+6`（不分解）也判对 | `safe_compare` 只验证等价性，不验证结构 |

### 掌握度模型

| 限制 | 影响 | 缓解措施 |
|------|------|----------|
| **无时间衰减** | 3 个月前答对的题和 3 分钟前权重相同 | Beta-Binomial 本身不建模遗忘，需扩展 |
| **无跨 topic 迁移** | 掌握 `linear_equation` 不会加速 `quadratic_equation` 的学习 | 独立 Beta 分布，无联合建模 |
| **无题目难度校准** | 同一知识点的 easy/medium/hard 难度级别是手工定义的 | 模板参数范围硬编码，未采用 IRT 校准 |
| **固定 prior Beta(3,3)** | 所有学生起点相同，无先验知识评估 | 可后续改为自适应 prior |

### 推荐策略

| 限制 | 影响 | 缓解措施 |
|------|------|----------|
| **仅三层优先级** | 无 spaced repetition 调度、无 interleaving 策略 | 三层覆盖核心场景，简单可解释 |
| **挫折保护固定阈值** | 连续 3 错触发，不考虑题目难度 | 对 MVP 足够，个性化阈值需更多数据 |
| **无学习目标导向** | 系统不会"考前复习"或"专项突破" | 推荐全部由 mastery 状态驱动 |
| **前置门槛固定 0.6** | 所有 topic 使用相同解锁阈值 | 对当前 5 个 topic 合理 |

### 系统架构

| 限制 | 影响 | 缓解措施 |
|------|------|----------|
| **无持久化** | 刷新页面丢失所有进度 | 明确是 MVP，下一步加 JSON 文件存储 |
| **单用户** | 无法同时服务多个学生 | MasteryStore 非线程安全，需加 session 隔离 |
| **无认证** | 任何人均可访问 | MVP 不做用户系统 |
| **SymPy 性能** | `simplify` 对大表达式可能慢 | 当前题目规模（一元方程、简单积分）无性能问题 |
| **不支持中文数学符号** | SymPy 将中文解析为符号名，不会报错但无意义 | 输入验证接受中文但不判对 |

## 未来扩展方向（按优先级）

### 短期（可立即实现）

1. **JSON 文件持久化** — `MasteryStore.save(path)` / `MasteryStore.load(path)`，刷新不丢进度
2. **更多 topic** — 扩展至 8-10 个知识点：不等式、三角函数、对数、数列等
3. **解题步骤展示** — 错误时显示正确解法（如 `sympy.solve` 的分步结果）
4. **题目多样性增强** — 每个 topic 更多模板变体，减少模式感

### 中期（需设计）

5. **Spaced Repetition** — 结合遗忘曲线，安排最佳复习时机
6. **跨 topic 知识迁移** — Hierarchical Beta 模型，共享先验信息
7. **题目难度自动校准** — 基于历史正确率调整各模板的难度标签
8. **学习报告** — 对局总结、掌握度变化曲线、薄弱点分析

### 长期（研究方向）

9. **自由问答** — 学生输入任意数学表达式，系统判断等价性并分类到知识点
10. **多模态输入** — 手写公式识别（OCR），语音输入
11. **协作学习** — 多人解题对比、同伴教学
12. **自适应出题** — 不仅调难度，还调题目类型（计算/选择/填空）

## 不做的事情

| 方向 | 原因 |
|------|------|
| LLM 出题/判题 | 不可控、不可复现、有幻觉风险。LLM 仅用于教学反馈（解析/提示/鼓励），不对确定性逻辑做决策 |
| LangGraph / CrewAI | 过度框架化，违反 minimal 原则 |
| 微服务 | 学生项目，单体架构即可 |
| 数据库 | 当前 in-memory 足够，持久化用 JSON 文件更简单 |
| 用户系统 | MVP 不搞认证 |
| RL/bandit 推荐 | 过于复杂，确定性策略已足够且可解释 |
