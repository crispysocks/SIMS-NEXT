# 升学预测AI模块介绍

## 1. 产品简介

升学预测AI模块是SIMS-NEXT系统中的智能升学分析组件，基于学生历史考试成绩数据，运用数据分析和人工智能技术，为初中生提供科学的升学志愿建议和个性化的学习提升方案。

### 1.1 目标用户

- **初中学生**：了解自己的升学定位和志愿选择
- **班主任/老师**：掌握学生情况，指导学生志愿填报
- **学生家长**：辅助子女做出合理的升学规划

### 1.2 核心价值

- **数据驱动**：基于真实考试成绩，而非主观经验
- **智能分析**：自动识别风险科目，预测录取概率
- **个性化建议**：针对每个学生的特点给出定制化方案
- **实时交互**：AI对话式咨询，随时解答疑问

## 3. 核心功能详解

### 3.1 升学预测分析

根据学生当前分数和历史排名，计算各高中的录取概率。

**预测算法核心逻辑**：

| 因素 | 权重说明 |
|------|----------|
| 分数差 | 学生分数与学校录取线差值，差值越大概率越低 |
| 排名优势 | 学生排名与录取排名差距，排名越靠前概率越高 |
| 排名稳定性 | 历史排名波动情况，稳定学生概率更高 |
| 招生人数 | 学校招生规模，人数多竞争相对较小 |

**三档分类标准**：

| 档次 | 概率范围 | 说明 |
|------|----------|------|
| 冲刺 |< 40% | 录取存在不确定性，需要超常发挥 |
| 稳定 | 40% ~ 70% | 有较大希望被录取 |
| 保底 | ≥ 70% | 基本确定能被录取 |

### 3.2 AI对话咨询

基于MiniMax大模型，提供智能化的升学问答服务。

**支持的分析维度**：

- **成绩定位**：当前分数在全区/校的位置
- **志愿建议**：冲刺/稳定/保底学校的选择理由
- **提升方案**：针对性科目提分建议
- **风险提示**：哪些科目需要重点关注

**意图识别机制**：

| 意图类型 | 触发关键词 | 响应特点 |
|----------|------------|----------|
| 提分咨询 | 加、分、概率、提升 | 引用加分模拟数据 |
| 志愿选择 | 选、哪个、冲、保底 | 给出A/B/C选项 |
| 风险分析 | 为什么、原因、风险 | 一句话简短分析 |
| 学习画像 | 学习、特点、强项、弱项 | 描述学习风格 |
| 综合分析 | 分析、看看、情况 | 结构化分点输出 |

### 3.3 学习画像分析

通过历史成绩数据，分析学生的学习特点和能力分布。

**画像维度**：

- **学习类型**：稳定型、波动型、上升型、下降型
- **理科能力**：强/中/弱
- **英语能力**：强/中/弱
- **提升潜力**：高/中/低

### 3.4 风险预警

自动识别学生潜在的学习风险。

**风险标签类型**：

- 科目排名下滑
- 成绩波动过大
- 单科明显偏科
- 排名持续下降

### 3.5 加分模拟

模拟不同分数对应的录取结果变化。

**模拟维度**：

- 按目标分数模拟（+5/+10/+15/+20分）
- 按学校选择查看详情
- 显示分数变化后的概率变化

### 4.1 后端技术栈

- **框架**：FastAPI

### 4.3 核心API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/predict/{student_id}` | GET | 获取学生升学预测结果 |

## 6. 使用指南

### 6.1 教师操作流程

1. **进入预测页面**：从侧边栏选择"升学预测AI"
2. **选择学生**：从下拉列表选择要分析的学生
3. **查看预测结果**：页面自动展示该学生的预测分析
4. **启动AI对话**：点击"咨询AI"按钮打开对话窗口
5. **发送问题**：在对话框输入问题获取AI建议

### 6.2 常见使用场景

| 场景 | 操作步骤 |预期结果 |
|------|----------|----------|
| 了解学生定位 | 选择学生 → 查看预测卡片 | 显示冲刺/稳定/保底学校 |
| 分析风险科目 | 选择学生 → 查看风险预警 | 显示风险标签列表 |
| 模拟加分效果 | 选择学生 → 输入目标分数 → 点击模拟 | 显示新概率结果 |
| 咨询AI建议 | 选择学生 → 点击咨询AI → 输入问题 | AI给出针对性建议 |

### 6.3 注意事项

- 系统需要学生有至少2次以上的考试记录才能生成准确预测
- AI对话依赖MiniMax API服务，需确保网络畅通
- 预测结果仅供参考，实际录取以官方公布为准
- 风险预警基于历史数据统计，不能完全预测未来表现
